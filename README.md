# 号枢

中文名：**号枢** · 前缀 `haoshu` · 端口 **6300 / 11300**

## 骨架

**业务键入枢纽 → 关系进链接 → 属性进卫星（载荷哈希开版）→ 枢纽-链接-卫星互证**

皮：号卡 / 套餐 / 客户。去皮是 Data Vault，不是营业厅办号、不是积分商城。

## 冒烟

```bash
docker compose up -d --build
# http://127.0.0.1:6300 → 入湖灌样例 → 枢纽/链接/卫星 → 贯验
```

## 半截装载回滚（口径甲：单事务原子回滚）

全局只贯彻一种口径：**批内枢纽/链接/卫星正式写库与装载事务日志、批次成功标志同属一个事务**，
任一步失败整体回滚，正式三族该批增量自然为零；无段间提交，故无补偿器、无残留路径。
批号一次性，同批号重试被拒，重试须换新批号；崩溃悬挂的「装载中」批次由贯验失败闭。

- 批次状态机：`装载中 → 成功（同事务终结）｜ 失败（回滚后独立小事务记账）`
- 只读接口：`GET /api/贯验/半截回滚`（全量扫描）、`GET /api/贯验/半截回滚/{批号}`（批号、成败、三族该批增量、事务证据）
- 全局贯验新增检项「半截回滚零残留」：失败批零增量、成功批有同事务证据、无未终结批、无无账增量
- 演练（中段必失败批 / 外带残留 / 伪终结 / 悬挂 / 无账增量 / 正式已清扫仍标成功）：

```bash
cd backend && python3 tests/半截回滚演练.py
```
